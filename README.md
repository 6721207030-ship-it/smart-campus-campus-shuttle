# Smart Campus - Campus Shuttle (กลุ่มที่ 8)
เว็บตารางเดินรถรับส่งและวางแผนการเดินทางในมหาวิทยาลัย

## รายชื่อสมาชิกกลุ่ม
1. นายพัชรพล บุญอินทร์ส่ง (รหัสนักศึกษา: 6721207030)

## เว็บไซต์ที่เผยแพร่ (GitHub Pages)
- **URL:** https://6721207030-ship-it.github.io/smart-campus-campus-shuttle/   

## รายการฟีเจอร์ที่พัฒนา
- **F1:** ดึงข้อมูลสายรถ จุดจอด และตารางเวลาจากไฟล์ data/shuttle.json มาแสดงผลผ่าน DOM
- **F2:** คำนวณเวลารถคันถัดไปอัตโนมัติจากเวลาปัจจุบันของเครื่อง และมีระบบนับถอยหลัง
- **F3:** วางแผนการเดินทาง ต้นทาง-ปลายทาง คำนวณสายรถที่ผ่านและระยะเวลาเดินทาง
- **F4:** ตารางเวลาเดินรถฉบับเต็ม รองรับการสลับดูวันธรรมดา/วันหยุด
- **F5:** ระบบบันทึกจุดจอดโปรด ข้อมูลคงอยู่แม้รีเฟรชหน้าเว็บด้วย localStorage
- **F6:** ฟอร์มแจ้งปัญหาการเดินรถ พร้อมระบบตรวจความถูกต้องของข้อมูล (Validation) และบันทึกลง localStorage
- **ฟีเจอร์เสริม:** รองรับ Dark Mode และผังเส้นทางเดินรถแบบ Timeline Diagram

## แหล่งที่มาของข้อมูลจริง
- ข้อมูลสาย 1 (รถเวียนภายใน): ฝ่ายอาคารสถานที่และยานพาหนะของมหาวิทยาลัย
- ข้อมูลสาย 2 (รถสองแถว): สำรวจและจดบันทึกเวลาจริงที่ป้ายรถประจำทางบริเวณรอบสถาบันและแยกอิสรภาพ
